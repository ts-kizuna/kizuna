Declare per-route or per-group middleware that mirrors the routes structure. Every top-level group key must be present — use `[]` for public routes. TypeScript autocompletes the route keys and rejects keys that don't exist.

<AdapterTabs functionName="createMiddleware" />

## Parameters

```ts
createMiddleware(contract: Contract, map: MiddlewareMap): MiddlewareMap
```

| Parameter  | Type            | Description                                              |
| ---------- | --------------- | -------------------------------------------------------- |
| `contract` | `Contract`      | The contract from [`k.contract`](/docs/reference/kizuna) |
| `map`      | `MiddlewareMap` | An object mapping route keys to middleware arrays        |

The middleware type depends on the adapter:

| Adapter | Middleware type                                                                                       |
| ------- | ----------------------------------------------------------------------------------------------------- |
| Express | `RequestHandler` from `express`                                                                       |
| Fastify | `FastifyPreHandler` — `(request: FastifyRequest, reply: FastifyReply) => void \| Promise<void>`       |
| Hono    | `MiddlewareHandler<E>` from `hono`                                                                    |
| Next.js | `(request: NextRequest, route: NextMiddlewareRoute) => Response \| void \| Promise<Response \| void>` |

## Returns

The middleware map, type-checked against the routes. Pass it to [`createApi`](/docs/reference/create-api) as `middleware`.

## Example

```ts title="src/lib/middleware.ts"
import { createMiddleware } from '@ts-kizuna/hono';
import { contract } from './contract';

export const middleware = createMiddleware(contract, {
    users: [authenticate],
    health: [],
    members: {
        '*': [requireMember],
        listMembers: [authenticate],
    },
});
```

## Middleware map shape

The map mirrors the routes structure:

- **Every top-level group key is required** — prevents forgetting a group and leaving it unprotected
- **`[]` on a key** — explicit public route or group, no middleware
- **Array on a leaf key** — applies to that single route
- **Array on a group key** — applies to every route in that group
- **Nested object on a group key** — per-route middleware within the group (individual route keys are optional)
- **`'*'` in a nested group** — default middleware for routes not explicitly listed

```ts
export const middleware = createMiddleware(contract, {
    // Explicit public group
    health: [],

    // Group-level: applies to every route under "users"
    users: [authenticate],

    // Per-route within a group
    workspace: {
        getWorkspace: [authenticate],
        deleteWorkspace: [authenticate, requireOwner],
    },

    // Group default with per-route override
    members: {
        '*': [requireMember],
        listMembers: [authenticate],
    },
});
```

## Group defaults

Use `'*'` inside a nested group to set default middleware for all routes, then override individual routes as needed:

```ts
export const middleware = createMiddleware(contract, {
    members: {
        '*': [requireMember],
        listMembers: [authenticate],
    },
});
```

Every route under `members` receives `[requireMember]` except `listMembers`, which receives `[authenticate]`. Explicitly listed routes always take precedence over `'*'`.

## Passing to `createApi`

Middleware sits beside the router in [`createApi`](/docs/reference/create-api):

```ts
import { createApi } from '@ts-kizuna/hono';

export const api = createApi({
    contract,
    router,
    middleware,
});
```

## Prefer guards for access control

For authentication and authorization, define identities and the contract's `auth` map and pass a guard per identity to [`createApi`](/docs/reference/create-api). Guards run before the handler, extract the request's credential for you, and merge their result into the typed handler args. See the [Authentication guide](/docs/auth) and the [`createGuard` reference](/docs/reference/create-guard). Reach for `createMiddleware` only for framework middleware that predates guards.
