---
title: server.requestContext
description: Resolve a request-scoped value every handler receives.
---

`server.requestContext(name, run)` implements a request context provider declared with [`Kizuna.requestContext`](/docs/reference/kizuna-request-context). It runs on every route, never denies, and handlers read its value under the provider's name.

```ts title="src/lib/request-context.ts"
import { server } from './server';

export const captureAnalytics = server.requestContext('analytics', ({ headers }) => ({
    sessionId: headers['x-posthog-session-id'] ?? null,
}));
```
