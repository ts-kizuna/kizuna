Bind a contract to its router — and any per-route middleware — producing the API object an adapter mounts.

<AdapterTabs functionName="createApi" />

## Parameters

```ts
createApi({
    contract: Contract;
    router: Router;
    middleware?: MiddlewareMap;
}): Api
```

| Field        | Type            | Required | Description                                                                        |
| ------------ | --------------- | -------- | ---------------------------------------------------------------------------------- |
| `contract`   | `Contract`      | Yes      | The contract from [`k.contract`](/docs/reference/kizuna)                           |
| `router`     | `Router`        | Yes      | The handler tree from [`createRouter`](/docs/reference/create-router)              |
| `middleware` | `MiddlewareMap` | No       | Per-route middleware (see [`createMiddleware`](/docs/reference/create-middleware)) |

The Next.js adapter also accepts an `onError` callback alongside `router` and `middleware`.

## Returns

An API object carrying the contract, its router, and middleware. Mount it with the adapter's mount verb:

| Adapter | Mount                                                              |
| ------- | ------------------------------------------------------------------ |
| Express | [`createExpressEndpoints(api, app)`](/docs/adapters/express)       |
| Fastify | [`app.register(fastifyKizuna, { api })`](/docs/adapters/fastify)   |
| Hono    | [`createHonoEndpoints(api, app)`](/docs/adapters/hono)             |
| Next.js | [`createNextEndpoints(api)`](/docs/adapters/next) or `api.mount()` |

## Example

```ts title="src/lib/server.ts"
import { createApi } from '@ts-kizuna/express';
import { contract } from './contract';
import { router } from './lib/router';
import { requireUser } from './lib/guards';

export const api = createApi({
    contract,
    router,
    middleware: {
        users: [requireUser],
        health: [],
    },
});
```

See the [Mounting guide](/docs/building/mounting) for full setup with each adapter.
