---
title: KizunaServer.init
description: Bind a contract to a server handle for defining guards, request context, and the router.
---

`KizunaServer.init(contract)` returns a `server` handle bound to your contract. It is the server-side counterpart to `k`: define guards, request context, and the router without passing the contract again.

<AdapterTabs functionName="KizunaServer" />

## Parameters

```ts
KizunaServer.init(contract: Contract): { server: Server }
```

| Parameter  | Type       | Description                                                   |
| ---------- | ---------- | ------------------------------------------------------------- |
| `contract` | `Contract` | The contract from [`k.contract`](/docs/reference/kizuna-init) |

```ts title="src/lib/server.ts"
import { KizunaServer } from '@ts-kizuna/express';
import { contract } from './contract';

export const { server } = KizunaServer.init(contract);
```
