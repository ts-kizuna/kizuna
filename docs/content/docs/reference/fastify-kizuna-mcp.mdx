Fastify plugin that mounts a [Model Context Protocol](https://modelcontextprotocol.io) endpoint. Each route becomes an MCP tool that AI assistants can discover and call.

<InstallTabs packageName="@ts-kizuna/mcp" />

```ts
import { fastifyKizunaMcp } from '@ts-kizuna/mcp/fastify';
```

## Usage

```ts title="src/index.ts"
import Fastify from 'fastify';
import { fastifyKizuna } from '@ts-kizuna/fastify';
import { fastifyKizunaMcp } from '@ts-kizuna/mcp/fastify';
import { api } from './lib/api';

const app = Fastify();

app.register(fastifyKizuna, {
    api,
});
app.register(fastifyKizunaMcp, {
    api,
});

app.listen({
    port: 3000,
});
```

## Options

Register the plugin with `app.register(fastifyKizunaMcp, options)`.

| Option        | Type       | Required | Description                                                             |
| ------------- | ---------- | -------- | ----------------------------------------------------------------------- |
| `api`         | `Api`      | Yes      | API created with [`createApi`](/docs/reference/create-server#serverapi) |
| `path`        | `string`   | No       | Mount path (default: `'/mcp'`)                                          |
| `name`        | `string`   | No       | Human-readable name (default: `'MCP Server'`)                           |
| `version`     | `string`   | No       | Semantic version (default: `'1.0.0'`)                                   |
| `routeFilter` | `Function` | No       | Predicate to filter which routes become tools                           |

## Secured routes

Secured tools authenticate via the MCP transport request's headers, running the same [guards](/docs/reference/create-server#serverguard) as their HTTP endpoints. The plugin reads each identity's credential from those headers (`credentialHeaders`, populated automatically) and runs the guard per tool call — the handler receives the identity's context exactly as it would over HTTP, and a `deny(...)` becomes a tool error result.

Configure the MCP client to send the credential on its connection, for example an `Authorization` header:

```json
{
    "mcpServers": {
        "my-api": {
            "url": "http://localhost:8002/mcp",
            "headers": {
                "Authorization": "Bearer tok_ada"
            }
        }
    }
}
```

See the [MCP guide](/docs/mcp) for connecting clients, tool input structure, and standalone server usage.
