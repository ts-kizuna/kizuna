Generate an [OpenAPI 3.1.0](https://spec.openapis.org/oas/v3.1.0) document from a contract. Returns a renderer you call with `'json'` or `'yaml'`.

<InstallTabs packageName="@ts-kizuna/openapi" />

```ts
import { generateOpenApi } from '@ts-kizuna/openapi';
```

## Parameters

```ts
generateOpenApi(contract: Contract, options?: GenerateOpenApiOptions): OpenApiRenderer
```

| Parameter  | Type                     | Description                                                                                                                                      |
| ---------- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `contract` | `Contract`               | The contract from [`k.contract`](/docs/reference/kizuna-init)                                                                                    |
| `options`  | `GenerateOpenApiOptions` | OpenAPI generation options. Omit them and the options an installed [`openApiDocsPlugin`](/docs/reference/openapi-docs-plugin) was given are used |

## Options

| Option            | Type                                  | Default   | Description                                                                             |
| ----------------- | ------------------------------------- | --------- | --------------------------------------------------------------------------------------- |
| `info`            | `{ title, version, description? }`    | required  | OpenAPI `info` object                                                                   |
| `openApiVersion`  | `'3.1.0'`                             | `'3.1.0'` | OpenAPI specification version for the generated document                                |
| `servers`         | `{ url, description? }[]`             | —         | Server URLs                                                                             |
| `setOperationId`  | `boolean \| 'concatenated-path'`      | `false`   | Set `operationId` from the route key. Use `'concatenated-path'` to include parent keys. |
| `tags`            | `OpenApiTag[]`                        | —         | Top-level tag definitions                                                               |
| `operationMapper` | `(operation, route, id) => operation` | —         | Callback to transform each operation before it is added to the spec                     |

There are no security options — security is emitted from the contract automatically, so the spec can't drift from what the server enforces. See below.

## Returns

An `OpenApiRenderer` function:

```ts
renderer('json'); // OpenApiDocument object
renderer('yaml'); // YAML string
```

## Example

```ts
import { generateOpenApi } from '@ts-kizuna/openapi';
import { contract } from './contract';

const spec = generateOpenApi(contract, {
    info: {
        title: 'My API',
        version: '1.0.0',
    },
    servers: [
        {
            url: 'https://api.example.com',
            description: 'Production',
        },
    ],
    setOperationId: true,
});

// Serve as a JSON endpoint
app.get('/openapi.json', (_req, res) => {
    res.json(spec('json'));
});
```

## Security emission

Security is generated from the contract, not configured on the generator. Every [identity](/docs/reference/kizuna-identity) registered on [`Kizuna.init`](/docs/reference/kizuna-init) is emitted under `components.securitySchemes`, and every route the [`auth` map](/docs/reference/k-contract#the-auth-map) secures references those names in its `security` — with OAuth scopes where the map declares them. Public routes (`false`) get none.

With the `user` (bearer) and `member` (API key) identities and `workspace: 'member'` in the auth map, the document contains:

```yaml
components:
    securitySchemes:
        user:
            type: http
            scheme: bearer
        member:
            type: apiKey
            name: x-workspace-token
            in: header
paths:
    /workspace:
        get:
            security:
                - member: []
```

A [`custom`](/docs/reference/kizuna-identity#custom-identities) identity is the exception: OpenAPI can't describe its credential, so it emits no `securityScheme` and no `security`. Its routes instead carry an `x-kizuna-guarded` extension, keeping a protected-out-of-band route distinct from a public one.

Because the spec and the runtime [guards](/docs/reference/server-guard) both derive from the auth map, documented security is enforced security — there is nothing to keep in sync.

See the [OpenAPI guide](/docs/openapi) for Scalar integration, writing specs to disk, and breaking change detection.
