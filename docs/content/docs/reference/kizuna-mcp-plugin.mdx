---
title: kizunaMcpPlugin
description: Payload CMS plugin that mounts an MCP endpoint so AI assistants can call your API.
---

```ts
import { kizunaMcpPlugin } from '@ts-kizuna/mcp/payload';
```

## Signature

```ts
kizunaMcpPlugin(api: Api, options?: McpEndpointOptions): Plugin
```

| Parameter | Type                 | Required | Description                                                |
| --------- | -------------------- | -------- | ---------------------------------------------------------- |
| `api`     | `Api`                | Yes      | API created with [`createApi`](/docs/reference/create-api) |
| `options` | `McpEndpointOptions` | No       | Configuration options                                      |

Returns a Payload `Plugin` that registers the MCP endpoint. Use alongside [`kizunaPlugin`](/docs/reference/kizuna-plugin):

```ts
import { buildConfig } from 'payload';
import { kizunaPlugin } from '@ts-kizuna/payload';
import { kizunaMcpPlugin } from '@ts-kizuna/mcp/payload';
import { api } from './lib/api';

export default buildConfig({
    // ...
    plugins: [kizunaPlugin(api), kizunaMcpPlugin(api)],
});
```

The MCP endpoint is accessible at `/api/mcp`.

## Options

| Option        | Default            | Description                                   |
| ------------- | ------------------ | --------------------------------------------- |
| `path`        | `'/mcp'`           | Mount path for the MCP endpoint               |
| `name`        | `'MCP Server'`     | Human-readable name shown to AI assistants    |
| `version`     | `'1.0.0'`          | Semantic version string                       |
| `routeFilter` | excludes multipart | Predicate to filter which routes become tools |

See the [MCP guide](/docs/mcp) for connecting clients, tool input structure, and standalone server usage.
