---
title: k.auth
description: Type the auth map against your routes and identities, beside the routes.
---

<BetaNotice>

Auth is still settling. The `auth` map and its cascade may change before v2, so pin your version if you depend on them.

</BetaNotice>

`k.auth(routes, map)` returns the map typed against the routes and identities, for defining it beside the routes rather than inside `k.contract`:

```ts
export const auth = k.auth(routes, {
    users: false,
    members: 'user',
});

export const contract = k.contract({
    routes,
    auth,
});
```
