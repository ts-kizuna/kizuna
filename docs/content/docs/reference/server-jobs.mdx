---
title: server.jobs
description: Write a handler for each of the contract's jobs.
---

`server.jobs(handlers)` takes a handler for each of the contract's [jobs](/docs/jobs), mirroring the declaration including its nesting.

```ts title="src/server/jobs.ts"
import { server } from './server';

export const jobHandlers = server.jobs({
    sendDigests: async () => ({
        status: 200,
        body: {
            sent: await sendPendingDigests(),
        },
    }),
    billing: {
        reconcileInvoices: async ({ input }) => ({
            status: 200,
            body: {
                reconciled: await reconcile(input.since),
            },
        }),
    },
});
```

A job handler receives `input`, `throwError`, and `jobs`, so it runs the same whether a tick reached it, a queue delivered it, or a script called it. A job with no declared `result` may return nothing.

Pass the result to [`server.api`](/docs/reference/server-api) under `jobs`.
