---
title: server.guard
description: Implement one identity by turning the extracted credential into typed handler context, or denying the request.
---

`server.guard(identity, run)` implements one [identity](/docs/reference/kizuna-identity): it turns the extracted credential into the typed context handlers receive, or denies the request. One guard per identity; the [auth map](/docs/reference/k-contract#the-auth-map) decides which routes it protects.

```ts title="src/lib/guards.ts"
import { server } from './server';

export const requireUser = server.guard('user', ({ bearer, unauthenticated }) => {
    const session = bearer ? sessions.get(bearer.token) : undefined;
    if (!session) {
        return unauthenticated();
    }
    return {
        userId: session.userId,
    };
});
```

The credential arrives already parsed and typed, keyed by the identity's method (`bearer`, `apiKey`, `basic`, `oauth2`, `openIdConnect`), or `null` when the request carried none. Return the identity's `context` and `access` fields to allow the request; they reach handlers under `auth`, keyed by the identity's name. An [authentication-only identity](/docs/reference/kizuna-identity#authentication-only-identities) returns nothing on success.

Guard arguments:

| Property          | Description                                                                               |
| ----------------- | ----------------------------------------------------------------------------------------- |
| credential        | The extracted credential, keyed by the identity's method. `null` when absent.             |
| `params`          | The matched route's path params, for guards that check access to the resource in the URL. |
| `unauthenticated` | `(detail?) => GuardDenial`, rejects a credential that did not resolve.                    |
| `scopes`          | The matched route's required OAuth scopes (`string[]`, empty for non-scoped routes).      |
| framework context | The adapter's native request objects (`req`/`res`, `c`, `request`/`reply`, `request`).    |

## Denying

`unauthenticated()` rejects a credential that didn't resolve, using the identity's status: 401 by default. Pass a detail to explain the case (`unauthenticated('Session expired')`); the status stays the identity's, set once via [`onUnauthenticated`](/docs/reference/kizuna-identity#custom-identities).

A 401 carries the `WWW-Authenticate` challenge RFC 9110 asks for, naming the identity's scheme: `Bearer` for `bearer`, `oauth2` and `openIdConnect`, `Basic` for `basic`. `apiKey` and `custom` name no registered HTTP scheme, so they answer 401 without one.

A guard has no way to name a status, which keeps the two failures apart. Insufficient access is 403, raised by the framework from the [auth map](/docs/reference/k-contract#the-auth-map) before the handler runs, everywhere the route is reachable including [MCP](/docs/reference/mcp-plugin).
