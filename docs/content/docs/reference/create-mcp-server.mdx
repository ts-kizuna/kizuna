<BetaNotice>

MCP support is new and still settling. `createMcpServer` and the generated tool surface may change before v2, so pin your version if you depend on them.

</BetaNotice>

Create a raw [MCP](https://modelcontextprotocol.io) server from a ts-kizuna API. Use this when you want full control over the transport, for example stdio for CLI tools or SSE for custom setups.

To serve it from your app, install [`mcpPlugin`](/docs/reference/mcp-plugin) instead.

<InstallTabs packageName="@ts-kizuna/mcp" />

```ts
import { createMcpServer } from '@ts-kizuna/mcp/server';
```

## Parameters

```ts
createMcpServer(api: Api, options?: McpServerOptions): McpServer
```

| Parameter | Type               | Required | Description                                                 |
| --------- | ------------------ | -------- | ----------------------------------------------------------- |
| `api`     | `Api`              | Yes      | API created with [`server.api`](/docs/reference/server-api) |
| `options` | `McpServerOptions` | No       | Configuration options                                       |

## Options

| Option              | Default              | Description                                                                                                                    |
| ------------------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `name`              | `'MCP Server'`       | Human-readable name shown to AI assistants                                                                                     |
| `version`           | `'1.0.0'`            | Semantic version string                                                                                                        |
| `tools`             | every route          | Which routes become tools, keyed by route tree                                                                                 |
| `onlyReadOnly`      | `false`              | Keep only `GET`, `HEAD`, and `OPTIONS`                                                                                         |
| `instructions`      | built from your tags | Appended to the generated overview                                                                                             |
| `handlerContext`    | none                 | Extra context spread into every handler call                                                                                   |
| `credentialHeaders` | none                 | Headers of the MCP transport request, used to run guards on secured tools                                                      |
| `transportAuth`     | none                 | A scheme the transport already verified: its guard and gates are skipped, and `context` reaches handlers under `auth.<scheme>` |

`tools` is keyed by the route tree: a route it never mentions is a tool, `false` drops one or a whole group, and `'*'` sets a group default. See [Choosing which routes become tools](/docs/mcp#choosing-which-routes-become-tools).

Routes whose `contentType` is `multipart/form-data` or `application/x-www-form-urlencoded` are never tools, because MCP tool input is JSON.

## Secured routes

Each call to a secured tool runs the same [guard](/docs/reference/server-guard) pipeline as an HTTP request, extracting the credential from `credentialHeaders`.

Driving the transport yourself means passing those headers along. For stdio there is no HTTP request, so supply whatever the environment provides:

```ts title="mcp.ts"
const server = createMcpServer(api, {
    name: 'My API',
    credentialHeaders: {
        authorization: `Bearer ${process.env.API_TOKEN}`,
    },
});
```

## Returns

An `McpServer` instance from `@modelcontextprotocol/sdk`. Connect it to any transport.

## Example

```ts title="src/index.ts"
import { createMcpServer } from '@ts-kizuna/mcp/server';
import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';
import { api } from './api';

const server = createMcpServer(api, {
    name: 'My API',
    version: '1.0.0',
});

await server.connect(new StdioServerTransport());
```

See the [MCP guide](/docs/mcp) for connecting clients and tool input/output structure.
