---
title: new KizunaServer()
description: Turn a contract into a server handle for defining guards, request context, and the router.
---

`new KizunaServer(contract)` is a `server` handle bound to your contract, the server-side counterpart to `k`.

<AdapterTabs functionName="KizunaServer" />

## Parameters

```ts
new KizunaServer(contract: Contract, options?: ServerOptions): Server
```

| Parameter              | Type                                    | Description                                                  |
| ---------------------- | --------------------------------------- | ------------------------------------------------------------ |
| `contract`             | `Contract`                              | The contract from [`k.contract`](/docs/reference/k-contract) |
| `options.jobTransport` | `JobTransport`                          | Where a queued job goes. See [Jobs](/docs/jobs#transports).  |
| `options.onJobError`   | `(job: string, error: unknown) => void` | Called when a job queued without a transport rejects.        |

```ts title="src/server/server.ts"
import { KizunaServer } from '@ts-kizuna/express';
import { contract } from './contract';

export const server = new KizunaServer(contract);
```

## Returns

The handle, the serving surface for this contract:

| Method                  | Description                                                                                                        |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `server.guard`          | Define the guard for one identity. See [`server.guard`](/docs/reference/server-guard).                             |
| `server.requestContext` | Resolve one declared request-context value. See [`server.requestContext`](/docs/reference/server-request-context). |
| `server.router`         | Write typed handlers for the contract or one group. See [`server.router`](/docs/reference/server-router).          |
| `server.jobs`           | Write a handler for each declared job. See [`server.jobs`](/docs/reference/server-jobs).                           |
| `server.api`            | Assemble it all into the object you mount. See [`server.api`](/docs/reference/server-api).                         |

With jobs that you queue from your own code, name a transport here. Without one, `queue` runs the job in this process and it is lost on a crash:

```ts
export const server = new KizunaServer(contract, {
    jobTransport: myQueue,
});
```

A job queued without a transport has already outlived its request, so a failure has nowhere to report. `onJobError` is where it surfaces; without one it is logged.

```ts
export const server = new KizunaServer(contract, {
    onJobError: (job, error) => Sentry.captureException(error, { tags: { job } }),
});
```
