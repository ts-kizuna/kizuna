A ts-kizuna project has three parts:

1. **The contract** — your routes and their Zod schemas, in a package both sides import.
2. **The server** — handlers that implement those routes, mounted on your framework.
3. **The client** — built from the same contract, so it knows every route, input, and response.

This guide builds all three.

## Installation

Install `@ts-kizuna/core` — the package that defines routes and contracts.

<InstallTabs packageName="@ts-kizuna/core zod" />

ts-kizuna requires Zod 4. It leans on Zod 4 features directly, so older versions won't work.

Enable `strict` in your `tsconfig.json`. ts-kizuna's inference depends on it.

```json title="tsconfig.json"
{
    "compilerOptions": {
        "strict": true
    }
}
```

## 1. Define the routes

Bind your API surface once with `new Kizuna()` and export `k` — then group your routes with `k.routes`. Keep each piece in its own file (a package both your server and client import).

```ts title="k.ts"
import { Kizuna } from '@ts-kizuna/core';

export const k = new Kizuna();
```

`new Kizuna()` takes optional tags, identities, request contexts and validation settings — see [`new Kizuna()`](/docs/reference/kizuna) for the full options.

Because this setup declares no tags, `k.routes` is called with just the route map. Once you declare tags, pass the tag name first — `k.routes('users', { ... })` — and TypeScript checks it against the tags you declared. See [Contract](/docs/building/contract) for the tagged form.

Each route pairs a method and path with Zod schemas:

```ts title="routes.ts"
import { z } from 'zod';
import { ProblemDetailsSchema } from '@ts-kizuna/core/schemas';
import { k } from './k';

export const UserSchema = z.object({
    id: z.string(),
    name: z.string(),
    email: z.email(),
});

export const usersRoutes = k.routes({
    listUsers: {
        method: 'GET',
        path: '/users',
        query: z.object({
            page: z.number().int().min(1).default(1),
            limit: z.number().int().min(1).max(100).default(10),
        }),
        responses: {
            200: z.object({
                users: z.array(UserSchema),
                total: z.number(),
            }),
        },
    },
    createUser: {
        method: 'POST',
        path: '/users',
        body: z.object({
            name: z.string().min(1),
            email: z.email(),
        }),
        responses: {
            201: UserSchema,
            400: ProblemDetailsSchema,
        },
    },
    getUser: {
        method: 'GET',
        path: '/users/:id',
        responses: {
            200: UserSchema,
            404: ProblemDetailsSchema,
        },
    },
});
```

## 2. Bundle them into a contract

The contract is the one object you hand to both the server and the client. `k.contract` assembles your route groups; it carries the tags and any [custom validation codes](/docs/reference/k-issue) you configured on `new Kizuna()`. Give it its own file — `contract.ts`.

```ts title="contract.ts"
import { k } from './k';
import { usersRoutes } from './routes';

export const contract = k.contract({
    routes: {
        users: usersRoutes,
    },
});
```

## 3. Implement the server

Pick an adapter, here Express. `new KizunaServer()` binds the contract to a `server` handle, `server.router` supplies the handlers, `server.api` produces the API object, and the mount attaches it to your app.

<InstallTabs packageName="@ts-kizuna/express" />

`handlers` supplies one function per route in a group. Inputs arrive validated and typed; return values are checked against the contract's declared responses.

```ts title="src/lib/server.ts"
import { KizunaServer } from '@ts-kizuna/express';
import { contract } from '@shared/contract';

export const server = new KizunaServer(contract);
```

```ts title="src/lib/router.ts"
import { server } from './server';

export const router = server.router({
    users: {
        listUsers: async ({ query }) => {
            const users = await db.users.findMany({
                skip: (query.page - 1) * query.limit,
                take: query.limit,
            });
            return {
                status: 200,
                body: {
                    users,
                    total: await db.users.count(),
                },
            };
        },
        createUser: async ({ body }) => {
            const existing = await db.users.findByEmail(body.email);
            if (existing) {
                return {
                    status: 400,
                    body: {
                        detail: 'Email already in use',
                    },
                };
            }
            const user = await db.users.create(body);
            return {
                status: 201,
                body: user,
            };
        },
        getUser: async ({ params }) => {
            const user = await db.users.findById(params.id);
            if (!user) {
                return {
                    status: 404,
                    body: {
                        detail: 'User not found',
                    },
                };
            }
            return {
                status: 200,
                body: user,
            };
        },
    },
});
```

`server.api` binds the router into the API object the adapter mounts.

```ts title="src/lib/api.ts"
import { server } from './server';
import { router } from './router';

export const api = server.api({
    router,
});
```

Mount it on your app.

```ts title="src/index.ts"
import express from 'express';
import { api } from './lib/api';

const app = express();
app.use(express.json());

api.mount(app);

app.listen(3000);
```

## 4. Call it from a typed client

The client is built from the same contract, so every route, input, and response is already typed — no SDK to generate.

<InstallTabs packageName="@ts-kizuna/fetch" />

```ts title="src/lib/api-client.ts"
import { KizunaClient } from '@ts-kizuna/fetch';
import { contract } from '@shared/contract';

export const apiClient = new KizunaClient(contract, {
    baseUrl: 'http://localhost:3000',
});
```

```ts
const { body } = await apiClient.users.listUsers({
    query: {
        page: 1,
        limit: 10,
    },
});

console.log(body.users); // User[]

const result = await apiClient.users.createUser({
    body: {
        name: 'Alice',
        email: 'alice@example.com',
    },
});

// result.status is 201 | 400 — TypeScript narrows the body from there
if (result.status === 201) {
    console.log(result.body.id);
}
```

Every field — `query.page`, `body.name`, the response shape — is typed straight from the contract, with no extra work.
