The last step: `createApi` binds your [router](/docs/building/router) to the [contract](/docs/building/contract), producing the API object your framework adapter mounts. After this, your routes are live.

## `createApi`

```ts title="src/lib/server.ts"
import { createApi } from '@ts-kizuna/express'; // or @ts-kizuna/fastify, @ts-kizuna/hono, @ts-kizuna/next
import { contract } from './contract';
import { router } from './router';
import { requireUser, requireMember } from './guards';

export const api = createApi({
    contract,
    router,
    guards: {
        user: requireUser,
        member: requireMember,
    },
});
```

## Guards

If the contract declares identities, pass one guard per identity under `guards` — created with the adapter's `createGuard`, a guard verifies the extracted credential and returns the identity's context or a denial. The contract's auth map decides which routes each guard protects, so `createApi` attaches them automatically. See the [Auth guide](/docs/auth) for the whole pipeline and the adapter pages for each framework's guard context.

## Request context

For request-scoped values every handler needs — analytics ids, a logger, a tenant — declare them with [`createRequestContext`](/docs/reference/create-request-context), register them on `kizuna`, and resolve each with the adapter's `createRequestContextResolver`. Resolvers run on every route, never deny, and handlers receive their values typed under each name.

## Middleware

For everything else — rate limiting, multipart parsing — use your framework's own middleware (`app.use`, Fastify hooks). Authentication belongs in guards, request-scoped values in `requestContext`.

## Mounting

Once you have an `api` object, mount it with the adapter's mount verb:

**Express:**

```ts title="src/index.ts"
import express from 'express';
import { createExpressEndpoints } from '@ts-kizuna/express';
import { api } from './lib/server';

const app = express();
app.use(express.json());
createExpressEndpoints(api, app);
app.listen(3000);
```

**Fastify:**

```ts title="src/index.ts"
import Fastify from 'fastify';
import { fastifyKizuna } from '@ts-kizuna/fastify';
import { api } from './lib/server';

const app = Fastify();
app.register(fastifyKizuna, {
    api,
});
app.listen({
    port: 3000,
});
```

**Hono:**

```ts title="src/index.ts"
import { Hono } from 'hono';
import { createHonoEndpoints } from '@ts-kizuna/hono';
import { api } from './lib/server';

const app = new Hono();
createHonoEndpoints(api, app);

export default app;
```

**Next.js:**

```ts title="src/app/api/[...ts-kizuna]/route.ts"
import { createNextEndpoints } from '@ts-kizuna/next';
import { api } from '../../../lib/server';

export const { GET, HEAD, POST, PUT, PATCH, DELETE, OPTIONS } = createNextEndpoints(api, {
    basePath: '/api',
});
```
