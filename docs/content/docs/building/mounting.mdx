title: Mounting
description: Combine a contract and a router into an API object.
---

Once you have a contract and a router, combine them into an API object that an adapter can mount.

## `createApi`

```ts
// src/lib/server.ts
import { createApi } from '@ts-kizuna/express'; // or @ts-kizuna/hono, @ts-kizuna/next, @ts-kizuna/payload
import { contract } from './contract';
import { router } from './router';

export const api = createApi({
    contract,
    router,
});
```

## Mounting

Once you have an `api` object, pass it to the adapter's endpoint function:

**Express:**

```ts
// src/index.ts
import express from 'express';
import { createExpressEndpoints } from '@ts-kizuna/express';
import { api } from './lib/server';

const app = express();
app.use(express.json());
createExpressEndpoints(api, app);
app.listen(3000);
```

**Hono:**

```ts
// src/index.ts
import { Hono } from 'hono';
import { createHonoEndpoints } from '@ts-kizuna/hono';
import { api } from './lib/server';

const app = new Hono();
createHonoEndpoints(api, app);

export default app;
```

**Next.js:**

```ts
// src/app/api/[...ts-kizuna]/route.ts
import { createNextEndpoints } from '@ts-kizuna/next';
import { api } from '../../../lib/server';

export const { GET, HEAD, POST, PUT, PATCH, DELETE, OPTIONS } = createNextEndpoints(api, {
    basePath: '/api',
});
```

**Payload CMS:**

```ts
// payload.config.ts
import { buildConfig } from 'payload';
import { kizunaPlugin } from '@ts-kizuna/payload';
import { api } from './lib/server';

export default buildConfig({
    // ...
    plugins: [kizunaPlugin(api)],
});
```
