A router implements each route in your contract.

## `createRouter`

```ts
import { createRouter } from '@ts-kizuna/express'; // or @ts-kizuna/next
import { contract } from './contract';

export const router = createRouter(contract, {
    listUsers: async ({ query }) => {
        const users = await db.users.findMany({
            skip: (query.page - 1) * query.limit,
            take: query.limit,
        });
        return {
            status: 200,
            body: {
                users,
                total: await db.users.count(),
            },
        };
    },

    createUser: async ({ body }) => {
        const user = await db.users.create(body);
        return {
            status: 201,
            body: user,
        };
    },

    getUser: async ({ params }) => {
        const user = await db.users.findById(params.id);
        if (!user) {
            return {
                status: 404,
                body: {
                    message: 'Not found',
                },
            };
        }
        return {
            status: 200,
            body: user,
        };
    },
});
```

## Handler arguments

Each handler receives an object with the validated inputs for that route:

| Property     | Available when                       |
| ------------ | ------------------------------------ |
| `params`     | Route path has `:param` placeholders |
| `query`      | Route has a `query` schema           |
| `body`       | Route has a `body` schema            |
| `headers`    | Route has a `headers` schema         |
| `req`, `res` | Express adapter                      |
| `request`    | Next.js adapter                      |

## Return type

Return `{ status, body }` matching one of the route's declared responses. TypeScript enforces that the status and body match.

```ts
// Route: responses: { 200: UserSchema, 404: z.object({ message: z.string() }) }
return {
    status: 200,
    body: user,
};

return {
    status: 404,
    body: {
        message: 'User not found',
    },
};
```

For routes with typed response headers, include `headers` too:

```ts
return {
    status: 200,
    body: user,
    headers: {
        'x-request-id': req.headers['x-request-id'] ?? '',
    },
};
```

## Error responses

Use the `error` helper to return typed error responses. It accepts the same `{ status, body }` as a normal return but throws internally — useful in branching logic where you want to bail out early.

```ts
getUser: async ({ params, error }) => {
    const user = await db.users.findById(params.id);
    if (!user) {
        return error({
            status: 404,
            body: {
                message: 'Not found',
            },
        });
    }
    return {
        status: 200,
        body: user,
    };
},
```

TypeScript enforces that the status and body match the contract — same as a return value.

## Validation errors

When a request body or query fails schema validation, kizuna automatically returns a `400` response before the handler runs:

```json
{
    "message": "Validation failed",
    "issues": [
        { "path": ["email"], "message": "Invalid email" },
        { "path": ["phoneNumber"], "message": "Invalid phone number" }
    ]
}
```

The error messages in `issues` come directly from your Zod schemas in the contract. If you use custom messages in your schemas (e.g. `z.string().min(1, "Name is required")`), those messages are what the client receives.

You don't need to handle this yourself — kizuna validates against the contract and rejects invalid requests automatically.

This `400` response is reflected in the [fetch client](/docs/clients/fetch#validation-errors) return type and the [OpenAPI spec](/docs/open-api) for any route that declares a `body` or `query` schema.

If you declare your own `400` response in the contract, the client will see a union of both your type and kizuna's `ValidationError`. Use [`isValidationError`](/docs/clients/fetch#isvalidationerror) on the client to distinguish them.

## `RouteHandler` and `Router` types

Annotate handlers individually or as a group:

```ts
import type { RouteHandler, Router } from '@ts-kizuna/express';
import { contract } from './contract';

// Single route
const getUser: RouteHandler<typeof contract.getUser> = async ({ params }) => {
    const user = await db.users.findById(params.id);
    if (!user) {
        return {
            status: 404,
            body: {
                message: 'Not found',
            },
        };
    }
    return {
        status: 200,
        body: user,
    };
};

// All routes
const router: Router<typeof contract> = { ... };
```
