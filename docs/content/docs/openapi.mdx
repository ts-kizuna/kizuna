`@ts-kizuna/openapi` generates an [OpenAPI 3.1.0](https://spec.openapis.org/oas/v3.1.0) document from your contract.

<InstallTabs packageName="@ts-kizuna/openapi" />

## `generateOpenApi`

`generateOpenApi` returns a renderer — call it with `'json'` for the document object or `'yaml'` for a YAML string.

```ts
import { generateOpenApi } from '@ts-kizuna/openapi';
import { contract } from '@shared/contract';

const spec = generateOpenApi(contract, {
    info: {
        title: 'My API',
        version: '1.0.0',
    },
});

spec('json'); // OpenApiDocument object
spec('yaml'); // YAML string
```

## Deprecation

Routes and fields marked `/** @deprecated */` get `deprecated: true` in the generated spec — no extra options here. `generateOpenApi(contract)` reads them straight off the contract, once you've added the one-time build step. See [Deprecations](/docs/deprecations) for setup.

## Options

```ts
generateOpenApi(contract, {
    info: {
        title: 'My API',
        version: '1.0.0',
        description: 'Optional description',
    },
    servers: [
        {
            url: 'https://api.example.com',
            description: 'Production',
        },
        {
            url: 'http://localhost:3000',
            description: 'Development',
        },
    ],
    setOperationId: true,
});
```

| Option            | Default  | Description                                                                             |
| ----------------- | -------- | --------------------------------------------------------------------------------------- |
| `info`            | required | OpenAPI `info` object                                                                   |
| `servers`         | —        | Server URLs                                                                             |
| `setOperationId`  | `false`  | Set `operationId` from the route key. Use `'concatenated-path'` to include parent keys. |
| `tags`            | —        | Top-level tag definitions                                                               |
| `operationMapper` | —        | Callback to transform each operation before it is added to the spec                     |

## Security

Security comes from the contract, not from generator options. The [identities](/docs/auth) you register on `kizuna` are emitted as `components.securitySchemes`, and the contract's auth map becomes each operation's `security` — with oauth2 scopes included. There is nothing to declare here, and the spec can never disagree with what the server actually enforces.

```ts
export const user = createIdentity.bearer({
    context: z.object({
        userId: z.string(),
    }),
});
```

```yaml
# generated
components:
    securitySchemes:
        user:
            type: http
            scheme: bearer
paths:
    /workspace:
        get:
            security:
                - user: []
```

Routes marked `false` in the auth map get no `security` entry — they document as public, because they are.

## Serving with Scalar (Express)

```ts title="src/index.ts"
import express from 'express';
import { apiReference } from '@scalar/express-api-reference';
import { generateOpenApi } from '@ts-kizuna/openapi';
import { createExpressEndpoints } from '@ts-kizuna/express';
import { api } from './lib/server';
import { contract } from '@shared/contract';

const app = express();
app.use(express.json());

const spec = generateOpenApi(contract, {
    info: {
        title: 'My API',
        version: '1.0.0',
    },
});

app.get('/openapi.json', (_req, res) => {
    res.json(spec('json'));
});

app.use(
    '/reference',
    apiReference({
        url: '/openapi.json',
    })
);

createExpressEndpoints(api, app);
app.listen(3000);
```

## Serving with Scalar (Next.js)

```ts title="src/app/reference/route.ts"
import { ApiReference } from '@scalar/nextjs-api-reference';
import { generateOpenApi } from '@ts-kizuna/openapi';
import { contract } from '@shared/contract';

const spec = generateOpenApi(contract, {
    info: {
        title: 'My API',
        version: '1.0.0',
    },
    servers: [
        {
            url: '/api',
        },
    ],
});

export const GET = ApiReference({
    spec: {
        content: spec('json'),
    },
});
```

## Writing the spec to disk

```ts title="scripts/generate-openapi.ts"
import { writeFileSync } from 'fs';
import { generateOpenApi } from '@ts-kizuna/openapi';
import { contract } from '../src/contract';

const spec = generateOpenApi(contract, {
    info: {
        title: 'My API',
        version: '1.0.0',
    },
});

writeFileSync('openapi.yaml', spec('yaml'));
```

```sh
tsx scripts/generate-openapi.ts
```

## Validation errors

Routes with a `body` or `query` schema automatically include a `400` validation error response in the generated spec. This matches the error kizuna returns when request data fails schema validation.

If a route already declares a `400` response, the automatic validation error is not added — your declaration takes precedence.
