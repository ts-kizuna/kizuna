`@ts-kizuna/swift` generates a native Swift client from your ts-kizuna contract. The generated client uses `URLSession` and `Codable` — no third-party Swift dependencies required.

<InstallTabs packageName="@ts-kizuna/swift" />

## Generate

```sh
ts-kizuna-swift generate --contract src/contract.ts --output ios/MyApp/Generated/APIClient.swift
```

| Flag         | Description                                           |
| ------------ | ----------------------------------------------------- |
| `--contract` | Path to the TypeScript file that exports the contract |
| `--output`   | Output path for the generated `.swift` file           |

The CLI reads the contract at runtime using `jiti` — no build step needed. Add the generated file to your Xcode project or Swift package as a regular source file.

## Usage

```swift
let client = APIClient(baseURL: URL(string: "https://api.example.com")!)

let response = try await client.users.listUsers(page: 1, limit: 20)
print(response.body.users)
```

## Generated client

The generated file exports a typed actor with methods for each route and sub-clients for grouped routes:

```swift
import Foundation

public actor APIClient {
    public let baseURL: URL
    public let session: URLSession

    public var users: APIUsersClient { ... }

    public func listUsers(page: Int, limit: Int) async throws(APIClient.ListUsers.Failure) -> APIClient.ListUsers.Result {
        // ...
    }
}
```

## Deprecation

Routes and fields marked `/** @deprecated */` in the contract emit `@available(*, deprecated)` in the generated Swift code:

```swift
@available(*, deprecated)
public func deleteUser(id: String) async throws(APIClient.DeleteUser.Failure) {
    // ...
}
```

## Tip: automate with a script

You can add a script to your `package.json` to regenerate the client whenever the contract changes:

```json
{
    "scripts": {
        "generate:swift": "ts-kizuna-swift generate --contract src/contract.ts --output ../ios/MyApp/Generated/APIClient.swift"
    }
}
```
