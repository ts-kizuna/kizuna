---
title: Create a TypeScript Client Wrapper
description: Build a custom TypeScript client wrapper using the types and client from @ts-kizuna/fetch.
---

`@ts-kizuna/fetch` exports `createClient` and the full contract type system. You can wrap these to build hooks, an SDK layer, or any other integration — no generator needed.

> Want React Query hooks? Reach for [`@ts-kizuna/react-query`](/docs/clients/react-query) instead of building your own. This guide is for the cases it doesn't cover.

## Pattern

```ts
import { createClient, type Client, type ClientPayload } from '@ts-kizuna/fetch';
import { contract } from '@shared/contract';

const baseClient = createClient(contract, {
    baseUrl: 'http://localhost:3000',
});

export function createMyClient() {
    return {
        getUser: (id: string) =>
            baseClient.getUser({
                params: {
                    id,
                },
            }),
        createUser: (data: ClientPayload<typeof contract.createUser>['body']) =>
            baseClient.createUser({
                body: data,
            }),
    };
}
```

## Types

The key types from `@ts-kizuna/fetch`:

| Type                | Description                                                          |
| ------------------- | -------------------------------------------------------------------- |
| `Client<T>`         | The full typed client shape for a contract                           |
| `ClientArgs<R>`     | The full arguments for a single route (params, query, body, headers) |
| `ClientResponse<R>` | The response union for a single route, discriminated by `status`     |
| `ClientPayload<R>`  | Input types for one schema (a route's `body`, `query`, etc.)         |

These are fully generic — pass `typeof contract` or `typeof contract.someRoute` to get typed arguments and responses for your wrapper.

## Publishing

ts-kizuna does not maintain third-party client libraries. Build yours, publish it as its own package, and own it. See [Third-Party Clients](/docs/clients/third-party) to list it.
