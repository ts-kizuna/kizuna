---
title: Create a TypeScript Client Wrapper
description: Build and ship your own TypeScript client wrapper using the types and client from @ts-kizuna/fetch.
---

`@ts-kizuna/fetch` exports `createClient` and the full routes type system. You can wrap these to build hooks, an SDK layer, or any other integration — no generator needed.

New first-party client PRs will be declined — we can't maintain what we don't know well. The client API is public so you can build your own.

## Pattern

```ts title="src/lib/api-client.ts"
import { createClient, type Client } from '@ts-kizuna/fetch';
import { contract } from '@shared/contract';

const baseClient = createClient(contract, {
    baseUrl: 'http://localhost:3000',
});

export function createMyClient() {
    return {
        getUser: (id: string) =>
            baseClient.users.getUser({
                params: {
                    id,
                },
            }),
        createUser: (data: Parameters<typeof baseClient.users.createUser>[0]['body']) =>
            baseClient.users.createUser({
                body: data,
            }),
    };
}
```

## Types

The key types from `@ts-kizuna/fetch`:

| Type        | Description                                 |
| ----------- | ------------------------------------------- |
| `Client<T>` | The full typed client shape for your routes |

These are fully generic — pass `typeof routes` or `typeof routes.someRoute` to get typed arguments and responses for your wrapper.

## Publishing

ts-kizuna does not maintain third-party client libraries. Build yours and publish it as its own package.
