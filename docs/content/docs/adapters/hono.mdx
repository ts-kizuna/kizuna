`@ts-kizuna/hono` connects a ts-kizuna API to a [Hono](https://hono.dev) application. Hono runs on Cloudflare Workers, Deno, Bun, Node.js, and other runtimes — the adapter works the same everywhere.

**Requires Hono >= 4.**

<InstallTabs packageName="@ts-kizuna/hono hono" />

## Setup

The standard setup uses three functions:

- `createRouter` — bind typed implementations to the contract
- `createApi` — combine your contract, router, and middleware into an API object
- `createHonoEndpoints` — mount the API on a Hono app

```ts title="src/lib/router.ts"
import { createRouter } from '@ts-kizuna/hono';
import { contract } from '@shared/contract';

export const router = createRouter(contract, {
    users: {
        listUsers: async ({ query }) => {
            const found = await db.users.findMany({
                skip: (query.page - 1) * query.limit,
                take: query.limit,
            });
            return {
                status: 200,
                body: {
                    users: found,
                    total: await db.users.count(),
                },
            };
        },
        createUser: async ({ body }) => {
            const user = await db.users.create(body);
            return {
                status: 201,
                body: user,
            };
        },
        getUser: async ({ params }) => {
            const user = await db.users.findById(params.id);
            if (!user) {
                return {
                    status: 404,
                    body: {
                        detail: 'Not found',
                    },
                };
            }
            return {
                status: 200,
                body: user,
            };
        },
    },
});
```

```ts title="src/lib/server.ts"
import { createApi } from '@ts-kizuna/hono';
import { contract } from '@shared/contract';
import { router } from './router';

export const api = createApi({
    contract,
    router,
});
```

```ts title="src/index.ts"
import { Hono } from 'hono';
import { createHonoEndpoints } from '@ts-kizuna/hono';
import { api } from './lib/server';

const app = new Hono();
createHonoEndpoints(api, app);

export default app;
```

## Handler context

Each handler receives `{ params, query, body, headers, c }`. The `c` is the Hono `Context` object — useful when you need to access cookies, environment bindings, or other Hono-specific features.

```ts
getUser: async ({ params, c }) => {
    const token = c.req.header('Authorization');
    const user = await db.users.findById(params.id);
    return {
        status: 200,
        body: user,
    };
},
```

## Typed environment bindings

`createRouter` accepts a Hono `Env` type parameter for typed environment bindings. This is useful on runtimes like Cloudflare Workers where bindings are accessed via `c.env`.

```ts title="src/lib/router.ts"
import { createRouter } from '@ts-kizuna/hono';
import { contract } from '@shared/contract';

type AppEnv = {
    Bindings: {
        DB: D1Database;
        KV: KVNamespace;
    };
};

export const router = createRouter<typeof contract.routes, AppEnv>(contract, {
    users: {
        getUser: async ({ params, c }) => {
            const user = await c.env.DB.prepare('SELECT * FROM users WHERE id = ?').bind(params.id).first();
            return {
                status: 200,
                body: user,
            };
        },
    },
});
```

## Middleware

Per-route middleware is a plain Hono `MiddlewareHandler`. Declare which routes it runs on with a `middleware` map on `createApi`, shaped like your routes. Authentication is just middleware that sets context variables, which handlers then read via `c.get(...)`.

### Writing a guard

A guard is the common case: a middleware that allows or rejects a request. `createGuard` wraps that check so you skip the `next()` / `c.json()` boilerplate — call `deny(status, detail)` to reject, return to allow.

```ts title="src/lib/guards.ts"
import { createGuard } from '@ts-kizuna/hono';

type AuthEnv = {
    Variables: {
        userId: string;
        userRole: string;
    };
};

export const auth = createGuard<AuthEnv>(async ({ c, deny }) => {
    const token = c.req.header('authorization')?.slice(7);
    if (!token) {
        return deny(401, 'Unauthorized');
    }
    const session = await verifyToken(token);
    if (!session) {
        return deny(401, 'Unauthorized');
    }
    c.set('userId', session.userId);
    c.set('userRole', session.role);
});

export const requireAdmin = createGuard<AuthEnv>(({ c, deny }) => {
    if (c.get('userRole') !== 'admin') {
        return deny(403, 'Forbidden');
    }
});

export const requireMembership = createGuard<AuthEnv>(async ({ c, deny }) => {
    const membership = await checkMembership(c.get('userId'), c.req.param('id'));
    if (!membership) {
        return deny(403, 'Forbidden');
    }
    c.set('member', membership);
});
```

### Wiring middleware to routes

The map mirrors your routes. Every top-level group key must be present — use `[]` for public groups.

```ts title="src/lib/middleware.ts"
import { createMiddleware } from '@ts-kizuna/hono';
import { contract } from '@shared/contract';
import { auth, requireAdmin, requireMembership } from './guards';

export const middleware = createMiddleware(contract, {
    // Group-level: applies to all routes under "users"
    users: [auth],
    // Group default with per-route override
    members: {
        '*': [auth, requireMembership],
        listMembers: [auth],
    },
    // Multiple middleware compose left to right
    admin: [auth, requireAdmin],
    // Explicit public group
    health: [],
});
```

### Plugging into the API

```ts title="src/lib/server.ts"
import { createApi } from '@ts-kizuna/hono';
import { contract } from '@shared/contract';
import { router } from './router';
import { middleware } from './middleware';

export const api = createApi({
    contract,
    router,
    middleware,
});
```

Handlers access context variables set by guards via `c`:

```ts
getUser: async ({ params, c }) => {
    const userId = c.get('userId');
    // ...
},
```

## Options

```ts
createHonoEndpoints(api, app, {
    responseValidation: false,
});
```

| Option               | Default | Description                                                                                                                                                                                |
| -------------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `responseValidation` | `false` | Validate handler return values against response schemas. Enable in development.                                                                                                            |
| `formatError`        | —       | Reshape error (`>= 400`) response bytes for migrating clients — most don't need it (use Problem Details extension members). See [Migrating an existing API](/docs/migration/existing-api). |

## `RouteHandler` and `Router` types

Annotate handlers individually or as a whole tree:

```ts
import type { RouteHandler, Router } from '@ts-kizuna/hono';
import { contract } from '@shared/contract';

// Single route
const getUser: RouteHandler<typeof contract.routes.users.getUser> = async ({ params }) => {
    const user = await db.users.findById(params.id);
    if (!user) {
        return {
            status: 404,
            body: {
                detail: 'Not found',
            },
        };
    }
    return {
        status: 200,
        body: user,
    };
};

// Whole handler tree
const router: Router<typeof contract.routes> = { ... };
```
