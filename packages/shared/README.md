# @ts-kizuna/shared

`@ts-kizuna/shared` carries the implementation that [`@ts-kizuna/contract`](https://www.npmjs.com/package/@ts-kizuna/contract) and [`@ts-kizuna/server`](https://www.npmjs.com/package/@ts-kizuna/server) are built on. Both depend on it, so it arrives with them.

Install one of those instead. Nothing depends on importing this package directly, and its module layout changes between releases.
